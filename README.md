# Sceneory website

Official static marketing site for [Sceneory](https://sceneory.me/), an AI visual research assistant for Windows.

## Local preview

Serve the repository root with any static file server. For example:

```powershell
py -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment

The site is dependency-free and designed to deploy directly from the `main` branch root with GitHub Pages.
